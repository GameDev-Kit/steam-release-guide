# Steam Release Guide

A practical, community-driven guide to help game developers prepare, publish, and release a game on Steam.

This repository covers the essential steps and best practices for getting a game ready for Steam — from setting up your Steamworks app to preparing your store page, builds, launch, and post-release.

- 🛠️ **Steamworks Setup**
  - App configuration

  - Depots and builds
  - Branches and testing

- 📦 **Build & Distribution**
  - Preparing your game build

  - Launch checklist

## 🎯 Goal

The goal of this guide is to provide a simple and practical reference for indie developers who want to understand what is required to release a game on Steam without having to dig through hundreds of pages of documentation.

This is **not a replacement for the official Steamworks documentation**. It is a curated and simplified companion designed to make the process easier to understand and follow.
